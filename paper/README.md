# The paper

The PDF is third-party material and is not committed to this repository.

**Agrawal, A. K., Gans, J. S., & Goldfarb, A. (2025).** *The Economics of
Bicycles for the Mind*. NBER Working Paper 34034, 53 pages.

- Paper page: https://www.nber.org/papers/w34034
- DOI: https://doi.org/10.3386/w34034
- Direct PDF: https://www.nber.org/system/files/working_papers/w34034/w34034.pdf

The paper is an NBER working paper circulated for discussion and comment;
it is not a peer-reviewed journal publication. The course issue identifies a
53-page teaching copy, but the PDF is gitignored in that repository and the
NBER file currently returns a 403 to this research environment. Therefore,
only source metadata and public abstracts have been inspected, not the exact
page-level Proposition 3 text. See [SOURCE_AUDIT.md](../SOURCE_AUDIT.md).

**Version caution:** SSRN lists a separate 49-page version and a 2026 revision.
Do not use them interchangeably with the course's 53-page July 2025 PDF.

```bash
curl -L -o paper/agrawal-gans-goldfarb-2025-bicycles-for-the-mind.pdf \
  https://www.nber.org/system/files/working_papers/w34034/w34034.pdf
```

The `.gitignore` deliberately excludes `paper/*.pdf`.
